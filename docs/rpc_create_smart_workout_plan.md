# RPC: create_smart_workout_plan_rpc

## Objective
The objective is to save a multi-day workout plan generated by Gemini into the database in a single transaction. This RPC should create the `workout_plans` entry and all associated `workout_plan_days`, `workout_plan_day_exercises`, and `workout_plan_day_exercise_sets`.

## Input Parameters
- `p_user_id`: UUID (The user ID)
- `p_plan_data`: JSONB (The structured plan data from Gemini)
  - Must include `name`, `description`, `goal_type`, `plan_type`, `days_per_week`, etc.
  - `workouts`: Array of workout days
    - Each workout includes `name`, `day`, `focus`, and `exercises`.
    - Each exercise includes `exercise_id`, `order_in_workout`, `target_sets`, `target_reps_min`, `target_reps_max`, `current_suggested_weight_kg`, `on_success_weight_increase_kg`, etc.

## Logic
1.  **Insert into `workout_plans`**:
    - `user_id` = `p_user_id`
    - `name` = `p_plan_data->>'name'`
    - `description` = `p_plan_data->>'description'`
    - `goal_type` = `p_plan_data->>'goal_type'`
    - `plan_type` = `p_plan_data->>'plan_type'`
    - `created_by` = 'ai'
    - `is_active` = true (Deactivate other plans if necessary)
2.  **Loop through `workouts`**:
    - Insert into `workout_plan_days`:
      - `plan_id` = (newly created plan ID)
      - `day_number` = `workout->>'day'`
      - `name` = `workout->>'name'`
    - **Loop through `exercises`**:
      - Insert into `workout_plan_day_exercises`:
        - `workout_plan_day_id` = (newly created day ID)
        - `exercise_id` = `exercise->>'exercise_id'`
        - `order_in_day` = `exercise->>'order_in_workout'`
        - `target_sets` = `exercise->>'target_sets'`
        - `target_reps_min` = `exercise->>'target_reps_min'`
        - `target_reps_max` = `exercise->>'target_reps_max'`
        - `current_suggested_weight_kg` = `exercise->>'current_suggested_weight_kg'`
        - `on_success_weight_increase_kg` = `exercise->>'on_success_weight_increase_kg'`
        - `target_rep_increase` = `exercise->>'target_rep_increase'`
        - `target_rest_seconds` = `exercise->>'target_rest_seconds'`

## Output
- `plan_id`: UUID (The ID of the newly created workout plan)
